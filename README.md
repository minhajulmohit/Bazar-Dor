# 🛒 বাজার দর (BazarDor)

**বাজার দর** is a responsive market-price tracking web application that helps users explore essential products, compare prices, and identify products whose prices have increased or decreased.

## ✨ Key Features

- **Product Listings:** Browse products with names, units, prices, and price-change indicators.
- **Price Trends:** Explore sections for products with rising and falling prices.
- **Product Details:** View product summaries, minimum/maximum/average price information, and market-wise prices.
- **Category Browsing & Sorting:** Browse by category and sort by default order, lowest price, or highest price.
- **Authentication:** Sign in and sign up using Better Auth, with email/password and configured social sign-in providers.
- **Protected Pages:** Restrict profile and product-detail pages to signed-in users.
- **Profile Management:** View profile information and update your name.
- **Responsive Design:** Layouts for mobile, tablet, and desktop screens.
- **Loading States & Toasts:** Skeleton loaders and toast notifications provide feedback during supported actions.
- **Friendly Not Found Pages:** Help users return to the home page when a route or item is unavailable.

## 🧰 Technologies Used

- [Next.js](https://nextjs.org/) — React framework and App Router
- [React](https://react.dev/) — UI components
- [TypeScript](https://www.typescriptlang.org/) — Type-safe JavaScript
- [Tailwind CSS](https://tailwindcss.com/) — Styling
- [daisyUI](https://daisyui.com/) — UI components
- [Better Auth](https://www.better-auth.com/) — Authentication
- [React Hot Toast](https://react-hot-toast.com/) — Toast notifications
- [Lucide React](https://lucide.dev/) — Icons
- BazarDor Products API — Product and category data
